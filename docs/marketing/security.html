Account Security

  • Phone number verification — Every account is tied to a verified phone number via SMS code
  • Email verification — Email must be verified during registration
  • Secure PIN — Optional 6-digit secure PIN for additional authentication
  • Suspension system — Accounts detected violating Terms are suspended with appeal rights
  • Session management — View all active sessions and terminate any remotely

Biometric Protection

  • Fingerprint lock — Lock the entire app behind fingerprint authentication
  • Face ID — On supported devices, use Face ID to unlock the app
  • Per-chat biometric lock — Lock individual chats behind biometrics independently
  • Hardware-backed — Biometric data is stored in Android Keystore / iOS Secure Enclave, never on our servers

Chat Vaults

  • Biometric vaults — Lock sensitive chats behind fingerprint/Face ID
  • Secret code access — Use a custom secret code for additional chat vault security
  • Hidden from main list — Vaulted chats don't appear in the main chat list
  • Encrypted storage — Vaulted chat data is encrypted with an additional layer on top of E2EE

Anti-Screenshot Protection

  • SecureScreen — Sensitive chats use Android's FLAG_SECURE to prevent screenshots and screen recording
  • iOS ScreenShield — On iOS, screen recording detection prevents capturing sensitive chats
  • Burn-on-Read — Messages can be set to disappear immediately after being read
  • Notification redaction — Sensitive chat notifications hide message content on the lock screen

Burn-on-Read Messages

  • Messages self-destruct immediately after being read by the recipient
  • No trace left on either device or our servers
  • Combined with anti-screenshot for maximum security
  • Perfect for sharing sensitive information like passwords or one-time codes

Spam & Fraud Protection

  • Silence unknown callers — Calls from non-contacts are silenced and don't ring
  • Spam detection — Automatic detection of spam patterns and bulk messaging
  • Report & block — One tap to report and block spam senders
  • Suspicious link detection — Links are checked against known phishing/malware databases
  • Account restrictions — New accounts have rate limits to prevent spam campaigns

Suspicious Link Detection

  • Links in messages are scanned against real-time threat databases
  • Known phishing links show a warning before opening
  • Malware-hosting URLs are blocked entirely
  • Link previews show the true destination URL

Device Management

  • Active sessions — View all devices logged into your account with a clean, easy-to-read session manager
  • Terminate individual sessions — Log out of any device remotely
  • Terminate all — Log out of all devices at once
  • Trusted devices — Devices used for 30+ days can be marked as trusted (skip verification)
  • Persistent device ID — Uses ANDROID_ID / identifierForVendor so you don't re-verify after reinstall
  • New device alerts — You're notified when someone logs in from a new device

Passkeys & Two-Factor Authentication

  • Passkeys — Passwordless authentication using device biometrics (FIDO2/WebAuthn)
  • Two-factor authentication — Optional 2FA via email or SMS code
  • Secure PIN — Additional 6-digit PIN required for sensitive actions
  • Passkey management — View and revoke passkeys per device

Server Security

  • TLS 1.3 — All connections between app and servers use TLS 1.3 encryption
  • Encrypted at rest — All data stored on servers is encrypted at rest
  • No plaintext storage — Message content is stored as E2E encrypted ciphertext only
  • Rate limiting — API endpoints are rate-limited to prevent abuse
  • Regular updates — Server software is kept current with security patches
  • Access controls — Server access is restricted to authorized personnel only, with audit logging

Bug Bounty Program

We reward security researchers who help us find and fix vulnerabilities:

SeverityExamplesReward
CriticalRCE, authentication bypass, E2EE bypassUp to $5,000
HighData exposure, privilege escalation, session hijacking$1,000 - $2,500
MediumXSS, CSRF, logic flaws$250 - $500
LowInformation disclosure, minor issuesRecognition + swag

Scope: Kora Messenger app (Android/iOS), backend API, and koramessenger.com. Out of scope: social engineering, physical attacks, DoS.

Responsible Disclosure

  • Report to: security@koramessenger.com
  • PGP key: Available on request
  • Response time: We acknowledge within 48 hours and provide a fix timeline within 7 days
  • Coordinated disclosure: We credit researchers and coordinate public disclosure after a fix is released
  • Please don't: Access others' data, modify data, degrade service, or publicly disclose before we fix it

Legal safe harbor: We won't take legal action against researchers who follow responsible disclosure guidelines and don't harm users.
