# Kora Messenger Support Knowledge

## Account Registration

Users can create a Kora Messenger account by:
1. Downloading the Kora Messenger app.
2. Tapping "Create account" on the welcome screen.
3. Entering their full name and email address.
4. Setting a secure password.
5. Verifying their email with the OTP code sent to their inbox.

A Kora ID is generated for each user after registration. This ID is used for adding contacts.

## Login

Users log in with their email and password.
- If login fails, users should verify their email and password.
- After 5 failed attempts, the account is temporarily locked for security.
- Trusted devices older than 1 month can bypass OTP verification.

## OTP Verification

Kora uses email-based OTP (One-Time Password) verification.
- The OTP code is sent to the user's registered email address.
- The code expires after a limited time.
- Users should check their spam/junk folder if they don't see the email.
- The app auto-verifies when the final digit is entered — no submit button needed.
- The app can auto-fill the code from the clipboard.

If a user does not receive their OTP:
1. Check the email address is correct.
2. Check spam/junk folder.
3. Wait a few moments and try again.
4. Request a new code if the current one expired.

## Password Recovery

Users can reset their password by:
1. Tapping "Forgot password?" on the login screen.
2. Entering their registered email address.
3. Receiving a verification code by email.
4. Entering the code (auto-verifies on final digit).
5. Setting a new password.
6. Being redirected to the login screen.

## Profile

Users can customize their profile with:
- Profile photo
- Bio
- Phone number
- Kora ID (unique identifier for adding contacts)

Profile settings are accessible from Settings or by tapping the profile image.

## Messaging

### Private Chats
Users can send text messages, images, documents, and voice notes in private chats.
Messages show delivery status with checkmarks:
- Single gray checkmark: sent
- Double gray checkmarks: delivered (recipient online)
- Double blue checkmarks: read

### Groups
Users can create groups from the home screen 3-dot menu:
- Tap "New group"
- Select contacts and Kora users
- Search by Name, Kora ID, or @Username
- Set group name and details

### Voice Messages
Users can send voice notes by:
- Tapping and holding the microphone icon in the chat composer
- Releasing to send or sliding to cancel
- The recipient can play the voice note and view transcription/translation

### Media
Users can share images, documents, and files in chats.
Images are cached with a 30MB limit for performance.

## Calls

### Audio Calls
Users can make audio calls to contacts.
Call quality depends on network connection.

### Video Calls
Users can make video calls to contacts.
Camera and microphone permissions are required.

### Live Translation
Kora supports live call translation for supported languages.
Users can enable call translation from call settings.

## Translation

### Text Translation
Users can translate text messages by tapping a message and selecting "Translate."
Supports 100+ languages.
Translation preferences can be configured in Settings.

### Voice Translation
Voice notes can be transcribed and translated.
Users can access this by tapping a voice note and selecting "Translate."

### Call Translation
Live call translation provides real-time translation during calls.
Configurable in Settings → Translation.

Translation settings include:
- Preferred language
- Auto-translate mode (off, always, ask)
- Show original text toggle
- Caption size
- Translate voice notes toggle
- Call translation toggle

## Security

### App Lock
Kora Messenger provides an App Lock security feature.
Users can configure App Lock from:
Settings → Privacy/Security → App Lock

Available authentication methods depend on the device:
- PIN/passcode
- Fingerprint
- Face authentication

Users can configure when App Lock activates.

### Privacy
Kora Messenger respects user privacy.
- Messages are private between participants.
- Profile information is visible to contacts.
- Users can control their online status visibility.
- Screenshot protection is enabled on contact profile screens (FLAG_SECURE).

### Account Security
- Passkeys can be enabled for passwordless login.
- Trusted devices are tracked and managed in Settings.
- Devices must be at least 1 month old to be marked as trusted.
- Users can view and manage active sessions.

## Premium

### Subscription
Kora Premium is a subscription service that unlocks additional features.
Pricing details are available in the app under Settings → Premium.

### Premium Features
Premium features include:
- App icon customization (premium icons)
- Additional features as they are developed

### Badge
Premium users receive a verified-style badge.

The Kora Messenger app owner has a permanent premium override without payment.

## Notifications

Users receive push notifications for:
- New messages
- Group mentions
- Important account activity

Notifications use a custom monochrome icon on Android.
Users can configure notification preferences in device settings.

## Troubleshooting

### App Won't Open
1. Force close the app and reopen.
2. Check for app updates.
3. Clear app cache (Android Settings → Apps → Kora Messenger → Storage → Clear Cache).
4. Restart your device.
5. Reinstall the app if the issue persists.

### Messages Not Sending
1. Check your internet connection.
2. Check if the recipient has blocked you.
3. Try restarting the app.
4. Check if Kora servers are operational.

### Can't Receive Messages
1. Check your internet connection.
2. Verify notification settings are enabled.
3. Check if the app is in the background.
4. Ensure Do Not Disturb is not blocking notifications.

### Video/Audio Call Issues
1. Check camera and microphone permissions.
2. Ensure a stable internet connection.
3. Close other apps using the camera/microphone.
4. Try switching between audio and video.

### App Lock Issues
1. If you forgot your App Lock PIN, use the backup PIN login screen.
2. If biometric authentication fails, use the PIN fallback.
3. Restart the device if biometric sensors are unresponsive.

## Kora AI

Kora AI is the general-purpose AI assistant built into Kora Messenger.
It can help users with:
- Questions and explanations
- Writing and editing
- Translation assistance
- Coding help
- Analysis and brainstorming
- Image and document understanding
- Conversation memory

Kora AI is a free feature for all users, regardless of premium status.

Kora AI should never be confused with Kora AI Support.

## Kora AI Support

Kora AI Support helps users troubleshoot Kora Messenger and understand Kora features.

It should not claim to have changed an account setting unless an authorized Kora backend operation has actually completed the change.

If a problem requires human support or protected account access, Kora AI Support will tell the user that the issue needs additional support.

## Contact

For issues that Kora AI Support cannot resolve, users can:
- Visit the help center
- Contact Kora Support through the app
- Report bugs through the in-app crash report system
